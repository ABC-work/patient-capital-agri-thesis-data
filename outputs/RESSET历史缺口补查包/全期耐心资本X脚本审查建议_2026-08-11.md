# 全期耐心资本X脚本审查建议

审查对象：`scripts/extract_resset_insholdshr_zip.py`与`scripts/construct_patient_capital.py`。本文件只提出审查结论和补丁建议，没有修改脚本。

## 已经足够的部分

### 提取与版本排序

`extract_resset_insholdshr_zip.py`已经：

- 将`StatDt`和`UpDt`解析为日期；
- 将`nobs/resset_row_id`解析为数值；
- 在`latest_stat_date`模式下依次按股票代码、年份、`StatDt`、`UpDt`、`resset_row_id`排序后保留最后一行；
- 保留保险、社保、企业年金的持股数、比例、持股户数，以及总股本/A股/无限售流通A股的机构合计诊断字段。

该顺序符合本轮实证审计：同一公司—年末的多行是随披露日期累积更新的快照，应该取最新版本，不能平均或求和。

### 结构性零值

`construct_patient_capital.py`要求某类别的比例、持股数和持股户数三项要么全有、要么全空，并仅在对应口径的机构合计字段非空时把全空解释为结构性0。该规则保守且可审计，能够避免把整行缺失误补为0。

### 比例和年度规则

脚本明确要求人工指定比例单位，转换后检查`[0,1]`范围，并只保留12月31日记录，不用三季度替代。这些规则可以保留。

## 建议修补的两处

### 1. 构造脚本的重复版本排序不完整

当前`construct_patient_capital.py`遇到公司—年份重复时只按`stat_date`排序：

```python
df = df.sort_values("stat_date").drop_duplicates(key, keep="last")
```

这没有复用提取脚本已经采用的`UpDt/resset_row_id`二级版本规则。同一天未来若出现更正版本，结果可能依赖输入文件原顺序。

建议：在`duplicate_policy=latest_stat_date`时要求并解析`stat_date`、`update_date`和`resset_row_id`，然后按：

```python
version_order = ["stock_code", "year", "stat_date", "update_date", "resset_row_id"]
df = df.sort_values(version_order).drop_duplicates(["stock_code", "year"], keep="last")
```

如果输入已经是`latest`文件且不存在重复，这一修改不改变现有结果；它用于防止未来合并原始批次时产生不确定性。

### 2. `002566-2020`需要双口径输出

`002566-2020`的三类机构字段全部为空，`all_institution_hold_pct_total`也为空，但其`InfoSource=年度报告`、前十大股东持股数和比例有效。现有保守规则会令`PatientCapital_total`缺失。

建议同时输出：

- **保守口径**：维持现有结果，即只有对应机构合计非空才补结构性0；`002566-2020`保持缺失。
- **扩展覆盖口径**：总股本口径允许在“机构合计非空”或者“前十大股东字段非空且来源为年度报告/更正公告”等有效年报证据存在时补0；此时`002566-2020=0`。

建议变量名：

- `patient_capital_total_conservative`；
- `patient_capital_total_top10_fallback`；
- `structural_zero_evidence`，取值如`institution_total`、`annual_report_top10_fallback`、`not_zero`、`insufficient`。

该回退只用于总股本口径。不能用总股本前十大股东比例证明A股或无限售流通A股口径的结构性0；后两种稳健性口径继续要求各自机构合计诊断字段非空。

## 其他非阻塞建议

- 构造结果可保留`stat_date`、`update_date`、`resset_row_id`和`info_source`，便于从最终X直接回查来源；至少应另存一张键—版本审计表。
- 合并到958条候选池时必须左连接并保留15条整行缺失，不能因为全期RESSET表里没有公司记录而自动补0。
- 当前全期X文件覆盖的是RESSET查询返回的所有公司—年份，其中包括部分上市前招股说明书快照；最终回归必须以内生样本公司—年份表为左表，不能直接把全期X文件的全部1,469行当作研究样本。
