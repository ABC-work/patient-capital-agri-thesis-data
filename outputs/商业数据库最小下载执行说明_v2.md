# 商业数据库最小下载执行说明（v2）

更新日期：2026-08-11

适用范围：兰州财经大学可访问的CSMAR与RESSET；目标研究期2013—2023年；股票范围采用`outputs/RESSET候选股票代码146只_每行一个_v1.txt`。逐包字段、条件和替代方案见`outputs/商业数据库最小下载清单_v2.csv`。

## 一、第一步现在就下载什么

先进入CSMAR的**公司研究系列（页面也可能显示为上市公司研究）→财务报表数据库**，依次打开：

1. 资产负债表；
2. 利润表；
3. 现金流量表。

三个表分别导出，不在平台跨表拼接。查询条件固定为：

- 股票：入口池146只，不是当前2023年的60只；
- 日期：2012-12-31至2023-12-31，2012用于增长率、平均资产和滞后变量；
- 频率：年度，只留12月31日；
- 报表：合并报表、年报、本期累计数、人民币；
- 标识字段：股票代码、公司名称、会计期间、报表类型、信息来源或公告日期（页面提供什么就保留什么）；
- 不选择单季数、母公司报表或调整前报表。

第一批最小字段：

- 资产负债表：总资产、总负债、固定资产净额、无形资产净额、货币资金、短期借款、一年内到期非流动负债、长期借款、应付债券、应收账款；
- 利润表：营业收入、营业成本、净利润、归母净利润、管理费用、财务费用、研发费用、利息费用或利息支出（若页面提供）；
- 现金流量表：经营现金流量净额、购建固定资产/无形资产/其他长期资产支付现金、支付给职工现金、购买商品接受劳务支付现金、分配股利利润或偿付利息支付现金。

字段英文代码不得凭经验输入。当前仓库没有CSMAR这些表的页面字段代码证据，下载时应连同字段说明或表头一起保存，清单统一标为“需在页面确认”。

| 5 | 专利数据 | 发明授权数、发明授权占比 | 146只及统一子公司范围 | 2013—2023 |

RESSET耐心资本X已完成全期构造，本轮不要重复下载`INSHOLDSHR`。已核实基准字段代码是`InsuComHoldPer`、`SocSecFdHoldPer`、`EntAnnuHoldPer`，追溯键是`StkCd`、`EndDt`、`StatDt`、`InfoSource`。

### 条件性后备包

- 如果CSMAR融资约束模块能直接导出SA、WW和KZ，**不下载**全市场分红和行业增长数据。
- 如果没有现成WW，SA仍可由146只的总资产和成立年龄计算；WW需要全A股非金融公司的行业销售增长和现金股利数据，届时再扩大范围，不能用146只候选池模拟行业增长。
- 如果能取得带算法说明的现成LP法TFP，**不下载**全A股TFP估计包。
- 如果没有现成TFP，才下载2012—2023年全A股非金融公司的产出、资本、劳动和中间投入，在较宽行业组内估计生产函数，再回填146只；不能只在57家或146只公司中估计行业生产函数。

这两个条件分支是控制下载规模的关键。

## 三、CSMAR页面应如何找表

以下名称是检索词和模块候选，不声称每个学校页面的菜单名称完全一致：

| 目标 | 页面检索词或候选路径 | 必须确认 |
|---|---|---|
| 财务报表 | 公司研究/上市公司研究→财务报表→资产负债表、利润表、现金流量表 | 是否有权限、合并报表标记、报表类型代码 |
| 公司信息 | 上市公司基本信息、公司概况、公司基本资料 | 成立日期是否历史可用、行业标准版本 |
| 员工 | 员工构成、员工专业构成、员工学历构成、人力资本 | 是否合并口径、技术/研发人员是否重叠 |
| 研发 | 研发投入、研发创新、研发人员 | 研发投入合计与利润表研发费用的区别 |
| 专利 | 上市公司专利、创新专利、专利年度统计、专利明细 | 申请/授权口径、母子公司范围、零记录含义 |
| 股东治理 | 第一大股东、股东持股、董事会特征、高管任职、实际控制人 | 年末口径、人员ID、控制权有效期 |
| 融资约束 | 中国上市公司经营困境研究数据库→融资约束 | SA/WW/KZ公式、正负方向、是否取绝对值 |
| TFP | 全要素生产率、企业生产率、公司效率 | LP/OP/OLS算法、投入产出定义和估计行业 |

CSMAR官方公开介绍已经确认“中国上市公司经营困境研究数据库”包含融资约束，但未公开证明本校页面的具体表名和SA/WW字段代码。因此，找到页面后要下载字段说明，不能只保存结果数值。

如果CSMAR某包显示无权限，再按CSV清单转到RESSET同类模块；不要同时下载两套全量重复数据。两库都有权限时，财务、员工、研发、治理优先选覆盖更完整且字段说明可保存的一库，另一库只抽取少量公司—年份做交叉核验。

## 四、合并下载与拆包规则

“允许合并下载”只指**同一张数据库表中的多个字段可一次勾选**，不表示不同表应在网页端拼成一个结果：

- 资产负债表字段可在一包；利润表另包；现金流量表另包；
- 员工年度汇总和人员明细若是两张表，分包；
- 专利年度汇总与专利明细分包；
- 董事会年度汇总与高管任职明细分包；
- 不同报表口径分包，禁止把合并和母公司报表放在同一分析文件后静默去重；
- 原始导出不手工改列名、不删除重复、不另存覆盖。

文件建议命名：

`数据库_模块_表名_股票范围_年份_报表口径_下载日期.原扩展名`

同时保存查询条件截图或文本、数据字典/字段说明、学校权限提示和原压缩包。商业原始数据不得上传公开GitHub。

## 五、各变量由哪些P0包产生

### Y八指标

- 本科及以上占比、技术人员占比：P0-05；
- 人均净固定资产：P0-01 + P0-05；
- 长期资产投资强度：P0-03 + P0-01的期初总资产；
- 无形资产强度：P0-01；扣土地后的口径需P1-03附注明细；
- 研发投入强度：P0-06 + P0-02；
- 发明授权数与发明授权占比：P0-07。

P0阶段若暂时无法拆分土地使用权，应将变量明确命名为“未扣土地的无形资产强度”。不能在论文中写成已扣除土地。P1取得附注明细后再替换并比较。

### M、控制和TFP

- SA：P0-01总资产 + P0-04成立日期；
- WW：优先P0-11A现成指标；自算才启用P0-11B和P0-13；
- Size、Lev、ROA、Growth、CFO：三张财务报表；
- ListAge：P0-04；Top1：P0-08；Board/Indep/Dual：P0-09；SOE：P0-10；
- TFP_LP：优先P0-12A；自算才启用P0-12B全市场包。

M1基准仍命名为“融资约束”。SA由规模和年龄构成、动态机制解释有限，所以即使首版先跑SA，也必须随后取得WW作替代。M2属于P1：先检查CSMAR或RESSET内部控制表；没有连续内控质量指标时，再用MD&A构造管理层短视主义。

## 六、每包下载后的最低质量检查

1. 股票代码按字符串读取并补足六位，只允许入口池代码；全市场后备包除外。
2. 检查`股票代码+会计年度+报表口径`重复，不能静默保留第一条。
3. 每年只留12月31日年报；核对累计数而非单季数。
4. 单位必须记录，特别是元、千元、万元和比例0—1/0—100。
5. 报告每字段逐年非缺失数和公司覆盖数；空白不能直接当0。
6. 资产恒等式、人员占比、专利分项合计、研发投入合计进行逻辑核验。
7. 下载后先与958条入口公司—年份左连接报告覆盖，不能先筛成当前已核实小样本再下载。

## 七、P1机制最小包

P0可以形成首版Y、控制、SA/WW和TFP。P1随后只需按结果与权限追加：

1. 内部控制评价、缺陷与审计意见；有连续指数则构造ICQ，无连续指数则用缺陷虚拟变量；
2. MD&A全文或词频及总词数，用于Myopia后备；
3. 无形资产附注明细，用于扣除土地使用权；
4. 利息支出附注，用于债务成本机制；
5. 机构调研事件，仅作外部监督扩展机制。

不要在P0尚未取得前下载大规模机构调研、盈余管理或全部年报文本，它们不阻塞首版主表和基准回归。

## 八、真实性边界

- 本清单的CSMAR/RESSET模块或表名中，除`INSHOLDSHR`、`MSHLSTANDOS`等已有登录审计明确核实者外，均是页面检索候选，实际名称需登录确认。
- 本轮未猜测任何CSMAR财务、员工、研发、专利、治理、融资约束或TFP字段代码。
- “学校可访问平台”不等于每个子库都有下载权限；每个模块都要实际点击日期、股票和字段选择后才算可用。
- 当前没有用模拟数据填充Y、M、控制或TFP，也没有提前假设回归结果显著。
