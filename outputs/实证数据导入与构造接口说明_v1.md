# 实证数据导入与构造接口说明 v1

本接口只接收真实导出数据；缺文件、缺字段、重复公司—年份、比例单位未确认时均直接报错，不生成模拟值。

## 1. 耐心资本

复制 `config/patient_capital_mapping.template.json`，按正式 RESSET 导出表头逐项修改键名，并在抽样用持股数量/总股本复核后，将 `ratio_unit` 明确设为 `percent` 或 `fraction`。运行：

```bash
python3 scripts/construct_patient_capital.py 原始导出.csv 实际映射.json patient_capital.csv
```

程序只保留 12 月 31 日记录；同一公司—年份多版本仅可依据 `stat_date` 取最新版本；三个机构分项任一缺失时，基准 X 保持缺失，不能自动当作零。

## 2. 新质生产力指数

按 `config/nqp_indicators.template.json` 准备审计后的三级指标。程序先按 1%/99% 缩尾，再正向标准化；零值保留为真实零，缺失不插补；维度内计算熵权，四个一级维度各占 1/4，避免指标较多的维度机械获得更高权重。运行：

```bash
python3 scripts/construct_nqp_entropy.py nqp_raw.csv config/nqp_indicators.template.json nqp.csv nqp_weights.csv
```

若融资机制改用研发投入，必须从配置中删除 `NQP_rdint` 后重算，避免机械相关。

## 3. 实证主表

财务和治理输入均须为唯一 `stock_code-year` 表。运行：

```bash
python3 scripts/build_empirical_master.py \
  --sample outputs/涉农候选公司年份_年报主营业务复核工作表_v15_跨年快速复核第五批.csv \
  --x patient_capital.csv --nqp nqp.csv \
  --financial financial.csv --governance governance.csv \
  --output empirical_master.csv --coverage merge_coverage.csv
```

主表默认只纳入已经人工复核且严格样本结论为“是”的记录。ST、退市整理期、核心变量完整性与缩尾须在得到实际覆盖报告后执行并留下逐步样本损失表，不能预先猜测最终样本量。

## 4. 当前阻断点

本地尚无 RESSET/CSMAR/Wind/CNRDS 的正式观测文件，因此现在可以完成接口与校验逻辑，但不能诚实地产出 X、Y、机制变量、描述统计或回归结果。最短路径仍是按 `商业数据库最小下载总清单_v1.csv` 先取得 P0 数据。
