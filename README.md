# 耐心资本与涉农企业新质生产力：样本识别数据

硕士论文暂定题目：

> 《耐心资本与涉农企业新质生产力——基于资源赋能与治理改善的双重机制》

本仓库保存涉农上市公司入口识别、农业产业化国家重点龙头企业匹配、ST/退市状态审计、年度报告主营业务复核、耐心资本构造方案及后续实证接口。

## 当前状态

- 入口候选池：958 条公司—年份、146 个股票代码，代码—年份无重复。
- 行业分类：已核实 2013—2021 年和 2023 年；2022 年逐公司行业分类仍待核实，未插值。
- 龙头企业：使用农业农村部官方名单动态展开，并区分上市公司法人本体与集团、母子公司。
- ST/*ST：已还原 33 个风险警示区间；入口池中 46 条公司—年份可确认当年曾处于风险警示。
- 年度报告：958 条公司—年份均取得巨潮资讯法定年报链接并完成业务复核；严格样本218条、扩展样本414条、边界50条、明确剔除329条，180条混合披露记录保留待核实口径。
- 耐心资本X：RESSET 2013—2023年末数据已构造；958条中943条匹配，942条按保守规则可用，15条历史记录待补查。
- 回归数据：Y、机制变量与控制变量的数据字典和导入脚本已建立，但CSMAR等正式数据尚未到位，当前不能运行正式回归。

## 重要声明

v33是当前年报业务复核权威主表，但严格、扩展及回归样本仍未最终冻结。2022年行业分类、180条混合披露口径、全量ST/退市整理期否定性审计及Y/控制变量覆盖仍待闭合。分行业与分产品收入不得机械相加；内部抵销或分部重叠无法拆分时正式分子保持为空。

## 数据来源

主要来源包括中国证券监督管理委员会、中国上市公司协会、农业农村部、上海证券交易所、深圳证券交易所和巨潮资讯网。每条结构化记录尽可能保留来源链接、文件名称、年份、匹配依据和复核状态。

## 使用提示

大 CSV 建议下载后使用 Excel、WPS、LibreOffice、R、Python 或 Airtable 打开。GitHub 网页可能无法直接渲染包含长年报摘录的文件，但仍可通过 **Download raw file** 下载。
